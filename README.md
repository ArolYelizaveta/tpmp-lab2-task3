# Лабораторная работа №2, задание 3 (Вариант 16)

## Overview

Данный проект представляет собой консольное приложение на языке C для работы со структурой `PRODUCT`, описывающей товар. Программа позволяет:

*   Вводить с клавиатуры данные о товарах (не менее 12 записей).
*   Выводить список товаров, отсортированный по дате производства (по возрастанию).
*   Выводить информацию о товарах, срок годности которых истекает в ближайшие двое суток (относительно текущей системной даты).
*   Подсчитывать и выводить общее количество товаров для каждого производителя.
*   Находить и выводить товар с максимальной ценой, срок годности которого ещё не истёк.

Проект организован в соответствии с моделью КИС (Клиент-Интерфейс-Сервер) и стандартами кодирования GNU. Сборка проекта осуществляется с помощью утилиты `make`. Для автоматизации сборки и тестирования используется GitHub Actions.

## Usage

*   Операционная система: Linux, macOS.

    ```bash

    ```
2. Выполните сборку с помощью:
    ```bash

    ```
